# Wrong-Answer Explanations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a detailed KO/EN explanation (clues → why the answer is right → why each wrong option is wrong, user's pick marked → key point) for every question of rounds 69–79, wherever a question is revealed.

**Architecture:** Explanations are generated once by Claude Code subagents reading the original question images, stored as static JSON in `data/explanations/{round}.json`, validated by a Node script, merged into `Question.explanation` by `getExam` at build time, and rendered by a new `Explanation` component inside `QuestionView` when `reveal` is on. The same run fills `data/era-map.json`.

**Tech Stack:** Next.js 16.4 (app router, static), React 19.3, TypeScript, Tailwind 4, Node 20.18 (`node:test` for script tests), Python pipeline `scripts/build_data.py` (era only).

**Spec:** `docs/superpowers/specs/2026-10-11-wrong-answer-explanations-design.md`

All paths below are relative to `app/`. **The project is not a git repository**, so there are no commit steps; tasks that modify generated data take a backup first instead.

## Global Constraints

- App stays fully static: no runtime AI, no API keys, no new npm dependencies.
- Explanation data lives in `data/explanations/{round}.json`, never inside `data/exams/` (regenerated by `build_data.py`).
- Both `ko` and `en` for every question; English keeps key Korean terms with a gloss, e.g. "주먹도끼 (hand axe)".
- `options` holds exactly the 4 wrong option numbers, ascending; the answer key in `data/exams/{round}.json` is the truth and is never contradicted.
- `era` ∈ `선사·고조선, 삼국·남북국, 고려, 조선 전기, 조선 후기, 개항기, 일제강점기, 현대`.
- `clues`: 1–6 non-empty strings; no empty strings anywhere.
- Generation works from the image `public/exams/{round}/qNN.webp`, not OCR text.
- No explanation → UI identical to today.
- Read `node_modules/next/dist/docs/` for any Next.js API used that is not already used in this codebase (AGENTS.md).

## Review Focus

1. **Blank answer (`mine` = null)**: no "your answer" tag anywhere, no crash → covered in Task 4 Step 6.
2. **User picked the correct answer (practice)**: tag sits on the ✅ line, not on a wrong-option row → Task 4 Step 6.
3. **Image-option / fallback questions** (`optionsAreImages`, `useFallback`, e.g. 69, 78, 79 have some): explanation still renders under the ①–⑤ grid → Task 8 Step 4.
4. **Partial data during rollout** (round file missing or a question missing): page renders without explanation and build does not fail → Task 3 Step 3 checks a round with no file.
5. **Key mismatch in generated data** (agent writes `options` containing the answer number or misses one) → validator test in Task 1 Step 1 (`rejects options that include the answer`).

```js
// Validation of generated explanations (data/explanations/{round}.json) against the exam's
// answer key. Pure functions; used by check_explanations.mjs and its tests.

export const ERAS = ["선사·고조선", "삼국·남북국", "고려", "조선 전기", "조선 후기", "개항기", "일제강점기", "현대"];

const filled = (s) => typeof s === "string" && s.trim() !== "";

function checkText(where, x, answer, errs) {
  if (!x || typeof x !== "object") return errs.push(`${where}: missing`);
  if (!Array.isArray(x.clues) || x.clues.length < 1 || x.clues.length > 6 || !x.clues.every(filled))
    errs.push(`${where}: clues must have 1–6 non-empty strings`);
  for (const k of ["identifies", "correct", "point"]) if (!filled(x[k])) errs.push(`${where}: ${k} is empty`);
  const want = [1, 2, 3, 4, 5].filter((n) => n !== answer);
  const got = Array.isArray(x.options) ? x.options.map((o) => o?.n) : [];
  if (JSON.stringify(got) !== JSON.stringify(want)) errs.push(`${where}: options must be [${want}] (got [${got}])`);
  for (const o of x.options ?? []) {
    if (!filled(o?.why)) errs.push(`${where}: option ${o?.n} why is empty`);
    if (o?.belongsTo !== undefined && !filled(o.belongsTo)) errs.push(`${where}: option ${o.n} belongsTo is empty`);
  }
}

/** Returns error messages for one round file; [] when valid. */
export function validateRound(exam, file, { partial = false } = {}) {
  const errs = [];
  const r = exam.round;
  if (file.round !== r) errs.push(`round ${file.round} does not match ${r}`);
  const qs = file.questions ?? {};
  const byNumber = new Map(exam.questions.map((q) => [String(q.number), q]));
  for (const key of Object.keys(qs)) if (!byNumber.has(key)) errs.push(`${r} q${key}: not in exam`);
  for (const [key, q] of byNumber) {
    const e = qs[key];
    if (!e) {
      if (!partial) errs.push(`${r} q${key}: missing`);
      continue;
    }
    if (!ERAS.includes(e.era)) errs.push(`${r} q${key}: unknown era '${e.era}'`);
    for (const lang of ["ko", "en"]) checkText(`${r} q${key} ${lang}`, e[lang], q.answer, errs);
  }
  return errs;
}
```

// Usage: node scripts/check_explanations.mjs [--partial] [--rounds 79,78] | --file <part.json>
import fs from "node:fs";
import path from "node:path";
import { validateRound } from "./lib/explanations.mjs";

const DATA = path.join(import.meta.dirname, "..", "data");
const args = process.argv.slice(2);
const partial = args.includes("--partial");
const ri = args.indexOf("--rounds");
const only = ri >= 0 ? new Set(args[ri + 1].split(",").map(Number)) : null;

const read = (p) => JSON.parse(fs.readFileSync(p, "utf8"));

// --file <part.json>: validate one agent part (partial) against its round and exit.
const fi = args.indexOf("--file");
if (fi >= 0) {
  const part = read(args[fi + 1]);
  const errs = validateRound(read(path.join(DATA, "exams", `${part.round}.json`)), part, { partial: true });
  errs.forEach((e) => console.log(e));
  console.log(`${Object.keys(part.questions ?? {}).length} explanations checked, ${errs.length} error(s)`);
  process.exit(errs.length ? 1 : 0);
}

const rounds = read(path.join(DATA, "exams", "index.json")).map((e) => e.round).filter((r) => !only || only.has(r));

let errors = 0;
let count = 0;
for (const r of rounds.sort((a, b) => a - b)) {
  const file = path.join(DATA, "explanations", `${r}.json`);
  if (!fs.existsSync(file)) {
    if (!partial) {
      console.log(`${r}: file missing`);
      errors++;
    }
    continue;
  }
  const expl = read(file);
  count += Object.keys(expl.questions ?? {}).length;
  const errs = validateRound(read(path.join(DATA, "exams", `${r}.json`)), expl, { partial });
  errs.forEach((e) => console.log(e));
  errors += errs.length;
}
console.log(`${count} explanations checked, ${errors} error(s)`);
process.exit(errors ? 1 : 0);

- [ ] **Step 6: Merge CLI** — `scripts/merge_explanations.mjs`

```js
// Merges agent output data/explanations/.parts/*.json into data/explanations/{round}.json.
// Entries from parts replace existing ones; questions are written in numeric order.
import fs from "node:fs";
import path from "node:path";

const DIR = path.join(import.meta.dirname, "..", "data", "explanations");
const PARTS = path.join(DIR, ".parts");
const read = (p) => JSON.parse(fs.readFileSync(p, "utf8"));

const byRound = new Map();
for (const name of fs.readdirSync(PARTS).filter((n) => n.endsWith(".json")).sort()) {
  const part = read(path.join(PARTS, name));
  const into = byRound.get(part.round) ?? {};
  Object.assign(into, part.questions);
  byRound.set(part.round, into);
}
for (const [round, questions] of byRound) {
  const file = path.join(DIR, `${round}.json`);
  const merged = { ...(fs.existsSync(file) ? read(file).questions : {}), ...questions };
  const sorted = Object.fromEntries(Object.entries(merged).sort(([a], [b]) => Number(a) - Number(b)));
  fs.writeFileSync(file, JSON.stringify({ round, questions: sorted }, null, 1) + "\n");
  console.log(`${round}: ${Object.keys(sorted).length} questions`);
}
```

const EXPLANATIONS = path.join(process.cwd(), "data", "explanations");

/** Generated explanations for a round, keyed by question number ("1"–"50"). */
function readExplanations(round: number): Record<string, Explanation> {
  const file = path.join(EXPLANATIONS, `${round}.json`);
  if (!fs.existsSync(file)) return {};
  return (JSON.parse(fs.readFileSync(file, "utf8")) as { questions: Record<string, Explanation> }).questions;
}

export function getExam(round: number | string): Exam | null {
  const file = path.join(DIR, `${Number(round)}.json`);
  if (!/^\d+$/.test(String(round)) || !fs.existsSync(file)) return null;
  const exam = JSON.parse(fs.readFileSync(file, "utf8")) as Exam;
  const explanations = readExplanations(exam.round);
  for (const q of exam.questions) {
    const e = explanations[String(q.number)];
    if (e) q.explanation = { ko: e.ko, en: e.en };
  }
  return exam;
}

"use client";
// Explanation (해설) of a revealed question: clues in the material, why the keyed answer is
// right, why each other option is wrong (the user's pick marked), and a takeaway.
import { usePrefs } from "@/lib/prefs";
import type { Choice, Explanation as ExplanationData } from "@/lib/types";
import { MARKERS } from "./QuestionView";

export function Explanation({
  explanation,
  answer,
  mine,
  collapsed = false,
  headingLevel,
}: {
  explanation: ExplanationData;
  answer: Choice;
  /** The user's choice (null = blank): tagged "your answer". */
  mine: Choice | null;
  /** Wrap in a closed <details> (notebook list). */
  collapsed?: boolean;
  headingLevel: "h3" | "h4";
}) {
  const { prefs, t } = usePrefs();
  const x = explanation[prefs.lang];
  const Heading = headingLevel;
  const label = "mb-1.5 text-xs font-bold tracking-wide text-ink-soft";
  const mineTag = <span className="shrink-0 text-xs font-bold text-bad">◀ {t.yourAnswer}</span>;

  const body = (
    <div className="space-y-4 font-sans text-sm leading-relaxed text-ink">
      <div>
        <p className={label}>🔎 {t.explClues}</p>
        <ul className="flex flex-wrap gap-1.5">
          {x.clues.map((c) => (
            <li key={c} className="rounded-[3px] border border-rule-soft bg-paper-raised px-1.5 py-0.5 font-serif">
              {c}
            </li>
          ))}
        </ul>
        <p className="mt-2">
          → <strong className="font-serif">{x.identifies}</strong>
        </p>
      </div>

      <div>
        <p className={label}>✅ {t.explWhyRight}</p>
        <p className="flex items-start gap-2">
          <span className="font-bold text-ok">{MARKERS[answer - 1]}</span>
          <span className="flex-1 font-serif">{x.correct}</span>
          {mine === answer && <span className="shrink-0 text-xs font-bold text-ok">◀ {t.yourAnswer}</span>}
        </p>
      </div>

      <div>
        <p className={label}>❌ {t.explWhyWrong}</p>
        <ul className="space-y-1">
          {x.options.map((o) => {
            const isMine = o.n === mine;
            return (
              <li
                key={o.n}
                className={`flex items-start gap-2 rounded-md border px-2 py-1 ${isMine ? "border-bad bg-bad-soft" : "border-transparent"}`}
              >
                <span className="text-ink-soft">{MARKERS[o.n - 1]}</span>
                <span className="flex-1 font-serif">{o.why}</span>
                {o.belongsTo && (
                  <span className="shrink-0 rounded-[3px] border border-rule-soft px-1 text-xs text-ink-faint">
                    {o.belongsTo}
                  </span>
                )}
                {isMine && mineTag}
              </li>
            );
          })}
        </ul>
      </div>

      <div>
        <p className={label}>💡 {t.explPoint}</p>
        <p className="rounded-md bg-paper-sunk px-3 py-2 font-serif">{x.point}</p>
      </div>
    </div>
  );

  if (collapsed) {
    return (
      <details className="mt-5 rounded-md border border-rule-soft px-3 py-2">
        <summary className="cursor-pointer font-sans text-sm font-medium text-ink underline decoration-dotted underline-offset-4">
          {t.showExplanation}
        </summary>
        <div className="mt-3">{body}</div>
      </details>
    );
  }
  return (
    <section className="mt-5 border-t border-rule pt-4" aria-label={t.explanation}>
      <Heading className="mb-3 font-serif text-base font-bold">{t.explanation}</Heading>
      {body}
    </section>
  );

// Copies the era of every generated explanation into data/era-map.json (the pipeline's input),
// keeping its _eras/_help keys. Rerun `npm run data` afterwards.
import fs from "node:fs";
import path from "node:path";

const DATA = path.join(import.meta.dirname, "..", "data");
const mapFile = path.join(DATA, "era-map.json");
const map = JSON.parse(fs.readFileSync(mapFile, "utf8"));
const dir = path.join(DATA, "explanations");
for (const name of fs.readdirSync(dir).filter((n) => /^\d+\.json$/.test(n))) {
  const { round, questions } = JSON.parse(fs.readFileSync(path.join(dir, name), "utf8"));
  map[String(round)] = Object.fromEntries(Object.entries(questions).map(([n, e]) => [n, e.era]));
  console.log(`${round}: ${Object.keys(questions).length} eras`);
}
fs.writeFileSync(mapFile, JSON.stringify(map, null, 2) + "\n");
